Memahami Tiga Pilar Utama Web

Setiap website modern dibangun di atas kombinasi harmonis dari HTML, CSS, dan JavaScript. Pelajari fungsi masing-masing pilar di bawah ini.

1. HTML (Kerangka & Struktur)

HyperText Markup Language adalah bahasa standar yang digunakan untuk membuat struktur halaman web. HTML mendefinisikan elemen seperti teks, gambar, tautan, formulir, dan tabel.

<!-- Contoh Struktur HTML -->
<div class="kartu">
  <h2>Halo Dunia!</h2>
  <p>Belajar web itu menyenangkan.</p>
</div>
Fungsi: Kerangka / Tulang Punggung Struktural

2. CSS (Desain & Estetika)

Cascading Style Sheets bertanggung jawab atas tata letak, warna, font, animasi transisi, dan responsivitas tampilan web agar indah dipandang di berbagai perangkat.

/* Contoh Styling CSS */
.kartu {
  background-color: #0f172a;
  border-radius: 1rem;
  box-shadow: 0 10px 25px rgba(0,0,0,0.5);
}
Fungsi: Tampilan & Animasi Visual Presentasional

3. JavaScript (Interaksi & Logika)

JavaScript adalah bahasa pemrograman yang menghidupkan web. JS memungkinkan manipulasi elemen secara dinamis, penanganan event klik, animasi kustom, hingga komunikasi data.

// Contoh Kode JavaScript
const tombol = document.getElementById('btn');
tombol.addEventListener('click', () => {
  alert('Tombol diklik!');
});
Fungsi: Perilaku & Interaktivitas Fungsional
